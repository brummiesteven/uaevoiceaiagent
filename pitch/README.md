# Pitch deck

`AlHammadi-pitch.html` — 17 slides, one file.

## Presenting it

Double-click the file. That's it.

It is entirely self-contained: system fonts, inline CSS and JavaScript, no images, no
external requests of any kind. **It runs off a laptop with no server and no internet**,
which is the point — venue wifi is not something to bet a pitch on.

| Key | |
|---|---|
| `→` `space` | next |
| `←` | back |
| `F` | fullscreen |
| click | next (the left 18% goes back) |

Copy it to the Desktop before presenting. Hunting through folders with a room watching is
an avoidable way to start.

## Two things to agree before you present

**Slide 8 is the one that lands.** The agent is asked for average rent in Dubai Marina, and
says it doesn't have that figure rather than inventing one. Don't rush it — a system that
knows what it doesn't know is the whole argument for putting this in front of the public.

**Slide 12 mentions Devin under the support loop.** That's D's work, not the MCP server.
Whoever fields questions on it should be the person who built it.

## Keeping it accurate

The figures on slides 4, 11 and 13 come from the live catalogue and were correct on
8 August 2026. If the numbers move, they're in the HTML as plain text — search for `598`.
Everything quoted on slides 6–8 is transcribed from real sessions with the agent, not
written for the deck.
